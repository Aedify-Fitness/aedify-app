## Non-Negotiable Acceptance Principles

- No test may approve behavior that expands product scope beyond the re-locked PRD.
- Local-only/offline-first behavior must be proven for every non-AI feature.
- BYOK secrets must never appear in Drift, `shared_preferences`, local files, logs, Crashlytics, exports, screenshots generated by tests, or debug fixtures.
- Durable structured app data belongs in Drift/SQLite. Simple non-critical preferences may use `shared_preferences`. Secrets use `flutter_secure_storage` only.
- AI outputs are never trusted directly. They must pass schema validation, deterministic business-rule validation, exercise matching, privacy filtering, and user review where required.
- Crashlytics is allowed only for crash diagnostics with strict redaction.
- Imported workouts/programmes, AI-generated workouts/programmes, and shared plans must never bypass preview/review/validation gates.
- Progress media and physique-analysis data stay local by default and are excluded from normal export/share flows.

## Consent Tests

Rules:

- AI physique analysis is optional.
- User must explicitly consent before selected media/frames are sent.
- Consent is per analysis action; do not assume consent from earlier media save.

Test cases:

1. User opens progress session and taps analyze.
2. Consent screen explains selected media/provider transfer.
3. User declines.
4. User accepts.
5. User cancels during provider call.
6. User deletes BYOK key before analysis.

Expected:

- No AI call without consent.
- Decline leaves media local and creates no analysis snapshot.
- Accept sends only selected media/frames and minimal metadata.

## Provider Gate Tests

- Missing key blocks.
- Text-only model blocks.
- Image-capable model allows.
- Offline blocks.
- Provider image limit exceeded triggers reduce-selection guidance.
- Provider timeout leaves no partial analysis snapshot.

## Media Selection Tests

Photo session:

- Select all four angles.
- Select subset if allowed.
- Missing angle warning.
- Unsupported/missing file path.

Video session:

- Extract representative frames locally.
- User confirms selected frames if UI supports.
- Full video is not sent if frame extraction is the chosen implementation.
- Frame extraction failure blocks or falls back safely.

Payload assertions:

- Selected media/frames only.
- Minimal comparison metadata only.
- No full profile.
- No lift logs unless explicitly needed and approved by PRD (default no).
- No API key in payload body/log.

## Structured Output Tests

Valid output must include:

- Rough body-fat range, not precise number.
- Confidence level.
- Limitations.
- Physique observations.
- Training-focused feedback.
- Safety-friendly language.

Invalid fixtures:

- Exact body-fat number only.
- Medical diagnosis.
- Attractiveness scoring.
- Body shaming.
- Extreme diet advice.
- Eating-disorder triggering instructions.
- Claims of clinical certainty.
- Raw chain-of-thought/reasoning.
- Prompt echoes.

Expected:

- Invalid outputs rejected or repaired.
- Non-repairable unsafe output becomes blocked/safe failure.

## Comparison Mode Tests

Supported comparisons:

- Baseline vs latest.
- Previous vs latest.
- Single-session analysis.

Test cases:

1. No baseline: comparison unavailable or prompts selection.
2. Baseline + latest selected: comparison output generated.
3. Previous + latest selected: comparison output generated.
4. Deleted baseline: comparison updates.
5. Mismatched angles: limitations flagged.

Acceptance:

- Comparison does not overstate visual changes.
- Analysis remains training-oriented and neutral.

## Snapshot Persistence Tests

Test cases:

- Save analysis snapshot locally.
- View past analysis.
- Delete analysis snapshot.
- Delete media session with linked analysis.
- Export `.aedifyplan` after analysis exists.
- Generate PDF after analysis exists.
- Trigger fake Crashlytics after analysis exists.

Expected:

- Snapshot stored locally only.
- Snapshot excluded from exports.
- Snapshot excluded from Crashlytics.
- Delete behavior removes or detaches snapshot according to retention rules.
