## Non-Negotiable Acceptance Principles

- No test may approve behavior that expands product scope beyond the re-locked PRD.
- Local-only/offline-first behavior must be proven for every non-AI feature.
- BYOK secrets must never appear in Drift, `shared_preferences`, local files, logs, Crashlytics, exports, screenshots generated by tests, or debug fixtures.
- Durable structured app data belongs in Drift/SQLite. Simple non-critical preferences may use `shared_preferences`. Secrets use `flutter_secure_storage` only.
- AI outputs are never trusted directly. They must pass schema validation, deterministic business-rule validation, exercise matching, privacy filtering, and user review where required.
- Crashlytics is allowed only for crash diagnostics with strict redaction.
- Imported workouts/programmes, AI-generated workouts/programmes, and shared plans must never bypass preview/review/validation gates.
- Progress media and physique-analysis data stay local by default and are excluded from normal export/share flows.

Expected:

## Forbidden Export Fields

Exports must never contain:

- API keys.
- User profile.
- Injuries/limitations.
- Lift logs or set logs.
- PRs/e1RM analytics.
- Body measurements.
- Progress photos/videos/thumbnails/extracted frames.
- AI prompts.
- Raw AI responses.
- Candidate exercise lists.
- Chat history.
- Import source files/excerpts.
- Image screenshots/enhanced images/artifacts.
- AI physique-analysis snapshots.
- Source reference content.

Test method:

- Seed all forbidden fields with unique sentinel strings.
- Export `.aedifyplan` and PDF.
- Search output bytes/text for sentinel strings.
- Test fails if any sentinel appears.

## PDF Export Tests

Required cases:

- PDF generated for single workout.
- PDF generated for multi-week programme.
- Prescription summary appears.
- Printable/open logging table appears.
- Actual log columns remain blank.
- Optional exercise-instructions appendix off by default.
- Appendix on when selected.
- Long programme paginates readably.
- PDF remains read-only and not importable in v1.

Acceptance:

- PDF is human-readable.
- PDF does not include forbidden fields.
- PDF does not imply it is an import format.
- Exercise instructions appendix does not make export unusably large by default.

## `.aedifyplan` Import Tests

### Valid Imports

- Import workout.
- Import multi-week programme.
- Import custom exercises.
- Import supersets.
- Import warm-up sets.
- Import exact prescription.

Expected:

- Imported item is inactive by default.
- Local editable copy is created.
- Custom exercise IDs are remapped to new local IDs.
- Exercise references are resolved safely.
- User previews before activation.

### Invalid Imports

- Wrong extension.
- Malformed JSON.
- Missing share schema version.
- Unsupported future schema.
- Invalid exercise references.
- Duplicate IDs within file.
- Forbidden fields present.
- Source excerpts present.
- Oversized file.

Expected:

- Import rejected safely.
- No partial programme persists.
- User receives clear error.
