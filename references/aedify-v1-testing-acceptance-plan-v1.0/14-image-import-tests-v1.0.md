## Non-Negotiable Acceptance Principles

- No test may approve behavior that expands product scope beyond the re-locked PRD.
- Local-only/offline-first behavior must be proven for every non-AI feature.
- BYOK secrets must never appear in Drift, `shared_preferences`, local files, logs, Crashlytics, exports, screenshots generated by tests, or debug fixtures.
- Durable structured app data belongs in Drift/SQLite. Simple non-critical preferences may use `shared_preferences`. Secrets use `flutter_secure_storage` only.
- AI outputs are never trusted directly. They must pass schema validation, deterministic business-rule validation, exercise matching, privacy filtering, and user review where required.
- Crashlytics is allowed only for crash diagnostics with strict redaction.
- Imported workouts/programmes, AI-generated workouts/programmes, and shared plans must never bypass preview/review/validation gates.
- Progress media and physique-analysis data stay local by default and are excluded from normal export/share flows.

## Multi-Image Ordering Tests

Rules:

- Multiple images show thumbnails.
- User can reorder screenshots.
- User-defined order becomes source order for AI extraction.

Test cases:

1. Select three screenshots in wrong order.
2. Reorder to week 1, week 2, week 3.
3. Confirm order.
4. Prompt builder includes order metadata.
5. AI draft maps content in user-defined order.
6. User cancels reorder.

Expected:

- AI never receives ambiguous unordered list without order metadata.
- Wrong order is recoverable before consent.

## Image Quality + Enhancement Tests

Enhancement is readability-only and must not change content.

Enhancement operations to test where implemented:

- Orientation correction.
- Rotation.
- Crop empty borders.
- De-skew.
- Brightness/contrast correction.
- Sharpening.
- Noise reduction.
- Upscaling where practical.

Test cases:

- Clean screenshot: no unnecessary enhancement or harmless pass-through.
- Dark screenshot: brightness/contrast applied.
- Rotated screenshot: orientation corrected.
- Slightly skewed screenshot: de-skew applied.
- Blurry screenshot: warning/low confidence.
- Cropped screenshot: unreadable/missing region flagged; not invented.
- Enhancement failure: original retained or import blocked with clear message.

Acceptance:

- Enhancement methods are recorded in metadata.
- Enhanced images are temporary artifacts.
- User can see warning/preview where practical.
- Enhancement does not silently alter numbers/text.

## Provider Gate Tests

Scenarios:

| Scenario | Expected Result |
|---|---|
| No BYOK key | Flow blocks before consent/send. |
| Text-only model | Image import disabled before prompt assembly. |
| Image-capable model | Flow proceeds after consent. |
| Capability unknown | Conservative block or verify path. |
| Provider image-count limit exceeded | Split/import guidance or block before send. |
| Offline | No AI call; user can retry later. |

## Consent + Payload Tests

Image import package may include:

- Selected original images.
- Enhanced images.
- Image order metadata.
- Image quality metadata.
- Enhancement methods.
- Import instructions.

Must not include:

- API keys.
- Lift logs.
- Injuries.
- Measurements.
- Chat history.
- Full user profile.
- Progress media unrelated to import.
- Unrelated private app data.

Tests:

- Decline consent: no provider call.
- Accept consent: payload includes only allowed fields.
- Inject sentinel profile/log/media data: absent from payload.

## AI Image Parse Tests

Fixtures:

- Valid single-workout screenshot.
- Valid multi-week programme screenshots.
- Cropped table returns missing/unclear items.
- Blurry image lowers confidence.
- Ambiguous units flagged unknown.
- AI guesses unreadable number.
- AI completes cropped table.
- AI includes source-image excerpt.
- AI includes prompt/raw reasoning.

Expected:

- Valid drafts pass schema/business validation.
- Guessing/invention/source-excerpt violations fail validation or repair to safe state.
- Unreadable content remains user-resolvable; not invented.

## Artifact Cleanup Tests

Scenarios:

1. Cancel before enhancement.
2. Cancel after enhancement before consent.
3. Decline consent.
4. Provider call fails.
5. Validation fails.
6. Save imported plan.
7. App killed during image import.
8. Cleanup job runs on next launch.

Expected:

- Temporary original/enhanced artifacts are deleted according to lifecycle policy.
- No artifacts appear in exports or Crashlytics.
- If import session persistence is implemented, metadata does not contain raw source excerpts.
